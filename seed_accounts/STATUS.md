# Seed Accounts — PDF Drop Folder

Drop Companies House annual report PDFs here. Tell Claude which files you've added and it will read them and update `market_sizing.py` directly.

## Naming convention
`{company_slug}_{fy_year}.pdf`
e.g. `mercedes_benz_cars_uk_2024.pdf`, `bmw_uk_2024.pdf`, `ford_uk_2023.pdf`

PDFs are gitignored — they stay local only.
